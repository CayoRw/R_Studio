# R_Studio

Olá. Bem-vindo ao repositório **R_Studio**! Aqui você encontrará o código e os dados necessários para realizar a atividade avaliativa de estatística.

## Arquivos incluídos
- **Atividade_Avaliativa.R**: Arquivo de código principal a ser executado no RStudio.
- **14idosos.xlsx**: Conjunto de dados utilizado no código.

## Como usar
1. Faça o download dos arquivos deste repositório para o seu computador.
2. Certifique-se de ter o software **RStudio** instalado.
3. Abra o arquivo `Atividade_Avaliativa.R` no RStudio.
4. Garanta que o arquivo `14idosos.xlsx` esteja no mesmo diretório que o código ou ajuste o caminho no script, se necessário.
5. Execute o código no RStudio.

## Requisitos
- RStudio instalado em sua máquina.
- Pacotes do R necessários (verifique no script quais pacotes são utilizados e instale-os previamente, caso necessário).
